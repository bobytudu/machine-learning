# Machine Learning Practice

This repository is dedicated to machine learning practice projects and experiments.

## Virtual Environment Setup

A Python virtual environment (`.venv`) is set up in this directory.

### Activating the Virtual Environment

Depending on your operating system and shell, run the appropriate command:

#### macOS / Linux

- **Bash / Zsh**:
  ```bash
  source .venv/bin/activate
  ```
- **Fish**:
  ```fish
  source .venv/bin/activate.fish
  ```
- **Csh / Tcsh**:
  ```csh
  source .venv/bin/activate.csh
  ```

#### Windows

- **PowerShell**:
  ```powershell
  .venv\Scripts\Activate.ps1
  ```
- **Command Prompt (cmd.exe)**:
  ```cmd
  .venv\Scripts\activate.bat
  ```
- **Git Bash**:
  ```bash
  source .venv/Scripts/activate
  ```

---

### Deactivating the Virtual Environment

To deactivate the virtual environment, simply run:

```bash
deactivate
```
